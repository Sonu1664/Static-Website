About SkillProbe

Built to Measure Real Skills,
Not Just Memory

SkillProbe was designed as an academic project to demonstrate how online skill assessments can be built using modern web technologies.

Our Mission

SkillProbe is an Online Skill Assessment Platform that allows learners, students, and job seekers to test their knowledge across multiple domains — from Web Development to Quantitative Aptitude — and receive instant, detailed feedback.

The platform features timed quizzes, automatic evaluation, and comprehensive scorecards that break down performance by topic, helping users identify their strengths and areas for improvement.

This project was built as part of a web development curriculum, demonstrating the practical use of HTML, CSS, and JavaScript to create a fully functional, responsive web application.
